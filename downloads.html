为什么会弹警告？

这两个工具暂时还没买官方签名证书（那是每年要花钱的，现在工具免费送，先省着）。Mac 和 Windows 系统见到没签名的软件，都会例行弹一次安全确认——这是系统对"新软件"的正常拦截，不是软件有问题，更不是病毒。零创自己天天在用，放心。

🍎 Mac 电脑会看到什么？

双击安装包时，系统可能提示：「macOS 无法验证开发者」

这么做（选一种）：

① 最稳：在安装包上 点右键 → 打开 → 仍要打开。

② 或者：系统设置 → 隐私与安全性 → 往下找到 「仍要打开」 → 点它 → 输密码确认。

放行一次，以后打开就正常了。

🪟 Windows 电脑会看到什么？

双击安装包时，屏幕可能提示：「Windows 已保护你的电脑」

这么做：点 「更多信息」 → 再点 「仍要运行」 → 就装上了。

如果浏览器下载时也弹「保留 / 不保留」，点 保留 继续。
